Button — the primary call-to-action control; use `primary` for the one main action on a screen, `outline`/`ghost` for secondary actions.

```jsx
<Button variant="primary">Save changes</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

Variants: primary (gold fill), secondary (teal fill), outline (bordered), ghost (text-only). Sizes: sm, md, lg. Supports `disabled` and a leading `icon`.
