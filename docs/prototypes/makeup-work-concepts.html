Makeup Work concepts

Four directions for the same short journey. Click through each one end to end, try pasting into the answer box, and switch to phone width. All content is sample.

What I cut

  • The grade field and the typed teacher name. Class is one tap.
  • A separate prayer screen. It now lives on the first screen.
  • "Next" after choosing a source. Choosing it moves you on.
  • Separate ponder and respond screens. One screen, one prompt.
  • Any sign-in. Name and class are enough; the teacher reviews.

Same in all four

  • Five screens: begin, choose, learn, reflect, commit.
  • Paste, drop and right-click are off in the answer box. Attempts are counted.
  • Voice is always an option next to typing.
  • The last screen shows what the teacher receives, including the effort summary.

Demo shortcuts

  • The learning timer is 8 seconds here. Admins would set the real length.
  • Voice recording is simulated. The real one would use the microphone.
  • Video and audio are stand-ins for the embedded players.
